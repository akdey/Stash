## 🎯 What This Micro-Frontend Is

A centralized, responsive, zero-BS command launchpad that connects all 19 software systems, autonomous agents, and utilities built across your workspace into a unified portal.

### ⚡ Core Capabilities
1. **Intelligent Direct-Routing Rule**:
   - **Hosted Applications** &rarr; Primary button: `Launch Hosted App ↗` opening the live cloud service (with an optional in-portal responsive live iframe preview modal).
   - **Repository & Local Engines** &rarr; Primary button: `View GitHub Repo ↗` opening the exact repository on `https://github.com/akdey/<repo>`.
2. **Real-Time Instant Search & Filtering**:
   - Keyboard shortcut `/` to focus search instantly.
   - Category filtering: *All*, *🟢 Hosted Only*, *🤖 Agents & Dev*, *📈 Financial Intel*, *🏛️ Enterprise & Legal*.
3. **Live Telemetry Counter**:
   - Displays real-time counts of active hosted deployments and open-source repositories.
4. **Zero-Dependency Portability**:
   - Built to run standalone without complex build steps. Double-click `index.html` to open immediately, or serve locally with `npm start`.

## 🏃 Quick Start

### Option 1: Direct File Open
Simply double click `index.html` or open it with your browser:
```bash
open index.html
```

### Option 2: Run via Local Server
```bash
cd AppLauncher
npm start
# Launches on http://localhost:3000
```

### Option 3: Deploy to Vercel in 10 Seconds
```bash
cd AppLauncher
vercel --prod
```
