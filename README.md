## 🎯 What STASH Is

A high-density, engineering-grade micro-frontend flight deck that connects all 20+ software systems, autonomous agents, and institutional engines built across Amit Kumar Dey's ecosystem into a unified command plane.

### ⚡ Architectural Features
1. **Intelligent Direct-Routing Protocol**:
   - **Hosted Applications** &rarr; `Initialize Live Host ↗` opens the live cloud production deployment, with interactive in-portal responsive live inspection drawers.
   - **Forensic Agents & Backend Engines** &rarr; `Audit Repository ↗` opens verified code repositories on `https://github.com/akdey/<repo>`.
2. **Multi-Modal Tactical Views**:
   - **Tactical Grid**: High-density engineering cards with real-time status indicators, architecture tier badges, and key metrics.
   - **Datasheet**: Compact system telemetry table with quick inspect triggers and instant filtering.
   - **Topology Graph**: Interactive system dependency & capability flow visualizer.
3. **Raycast-Style Quick Command Palette**:
   - Triggerable with `⌘K` or `/` from anywhere in the app for instant system hopping.
4. **Offline PWA & Edge-Optimized**:
   - Installable PWA with service worker caching, zero tracking, and instant Vercel edge deployment.
