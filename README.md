## 🎯 What STASH Is

A unified systems vault and micro-frontend launchpad that connects all 20+ software systems, autonomous agents, and institutional engines built across Amit Kumar Dey's ecosystem into a single command plane.

### ⚡ Architectural Features

1. **Embedded Portfolio Microfrontend (Hero)**:
   - Full-viewport live embed of [portfolio.akdey.vercel.app](https://portfolio.akdey.vercel.app/) — visitors immediately see the portfolio while demonstrating microfrontending in action.
2. **Flagship Projects**:
   - Marquee treatment for defining work: Hawk (autonomous forensic agent), BlueStar (enterprise ERP), Grip (wealth intelligence), and Blueprint (8-agent software council).
3. **Domain-Grouped Directory**:
   - Clean, searchable directory organized into four domains:
     - 🤖 **Agents & AI** — Hawk, Blueprint, HeyHuman, Botster, KAPS, AIControlPanel, DevOpsDebugger
     - 📊 **Finance & Markets** — SmokeRecon, Grip, Echo, AlphaStream
     - 🏢 **Enterprise** — BlueStar, VerdictLab, DocShield
     - 🎨 **Personal & Culture** — Molat, openGym, BestTake, LuminaPath, ApekStyleHumanoid
4. **Interactive In-Situ Inspection Drawer**:
   - Test hosted applications directly within the page across desktop, tablet, and mobile viewport presets.
5. **Quick Command Palette (`⌘K`)**:
   - Fast, keyboard-first navigation across all projects, tags, and capabilities.
6. **Offline PWA**:
   - Service worker caching, manifest, zero tracking, and edge-optimized delivery.
